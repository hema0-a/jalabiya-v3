تطبيق PWA متكامل لإدارة ورشة تفصيل الجلابيب — العملاء، الطلبات، المخزون، المالية، والإعدادات الاحترافية.

**الإصدار:** v3.2.0 — ✅ 4 تحسينات أولوية قصوى

## ✨ الميزات

### 📊 لوحة المعلومات
- ترحيب حسب وقت اليوم
- 4 مؤشرات رئيسية (KPIs): العملاء، الطلبات النشطة، إيرادات الشهر، مواعيد اليوم
- طلبات مستحقة قريباً
- مواعيد اليوم
- أحدث العملاء

### 👥 العملاء
- إضافة، تعديل، حذف (مع سلة محذوفات)
- بحث فوري (اسم أو هاتف)
- تصنيف VIP
- إحصائيات

### 📦 الطلبات
- 5 حالات: قيد الانتظار، قيد التنفيذ، جاهز، تم التسليم، ملغي
- ربط بعميل
- فلاتر بالحالة
- انتقال سريع للحالة التالية
- 3 طرق عرض: قائمة / كانبان / تجميع

### 💰 الدفعات
- تسجيل دفعات مرتبطة بالعميل
- 4 طرائق دفع: نقدي، InstaPay، Vodafone Cash، أخرى
- إحصائيات شهرية

### 🧵 المخزون
- تصنيف بالفئة: قماش، خيوط، إكسسوارات، أدوات
- تنبيه نقص (< 5)
- تعديل سريع للكمية (+1 / -1)

### 👷 العمال
- إضافة، تعديل، حذف
- تفعيل/تعطيل
- تتبع الرواتب

### 🧾 المصروفات
- 8 فئات (قماش، خيوط، إيجار، كهرباء، ...)
- فلاتر بالفترة (أسبوع، شهر، سنة)

### 📊 التقارير
- KPIs: الإيرادات، المصروفات، الربح
- رسم توزيع الطلبات
- أكثر العملاء دفعاً (Top 5)

### ⚙️ الإعدادات الاحترافية (13 قسماً)
- 🏢 معلومات الورشة + شعار
- 🎨 9 ثيمات + 3 Color Pickers
- 👁️ أوضاع العرض + الوضع الليلي
- 📏 حقول المقاسات (CRUD ديناميكي)
- 👔 أنواع الجلابيات + الأسعار
- 📦 المخزون والحدود
- 🔔 التنبيهات
- 💬 الرسائل التلقائية (5 قوالب)
- 💾 النسخ الاحتياطي (تصدير/استيراد JSON)
- ☁️ المزامنة السحابية (Firebase جاهز)
- 🖼️ ضغط الصور
- 🔒 الأمان (PIN + قفل تلقائي)
- ⚠️ منطقة الخطر

**البحث الفوري** + **فهرس جانبي** + **حفظ تلقائي**.

## 🚀 آخر التحسينات (v3.2.0)

**4 تحسينات أولوية قصوى** لرفع التطبيق إلى فئة أعلى:

### 1. ✅ صفحة الاختبارات (270 اختبار)

- **صفحة جديدة**: `src/pages/tests.js`
- **الوصول**: افتح التطبيق → `#/tests` → اضغط "▶️ تشغيل الاختبارات"
- **النتيجة**: 270/270 اختبار في Chrome + Safari
- **static imports فقط** (متوافق مع Safari)

### 2. ✅ معالج الأخطاء العالمي

- **`src/core/error-handler.js`** — يلتقط كل الأخطاء غير المعالجة تلقائيًا
- يسجّل في: Console + صفحة "سجل النشاط" + حلقة ذاكرة داخلية
- لا يوقف التطبيق عند أي خطأ

### 3. ✅ زر الإجراءات السريعة (FAB)

- **`src/ui/fab.js`** — زر عائم أسفل يسار
- عند الضغط → 4 إجراءات سريعة:
  - 📋 طلب جديد
  - 👤 عميل جديد
  - 💰 دفعة جديدة
  - 💸 مصروف جديد
- لا يظهر في `#/tests`

### 4. ✅ الحفظ التلقائي للمسودات (Autosave)

- **`src/services/draft-manager.js`** — حفظ تلقائي أثناء الكتابة
- **مُفعَّل في**: نموذج الطلب الجديد
- **الصلاحية**: 24 ساعة
- **السلوك**: أغلق النموذج بدون حفظ → أعد فتحه → تجد المسودة محفوظة

### 📝 تفاصيل كاملة

راجع [`CHANGELOG.md`](./CHANGELOG.md) للإصدارات السابقة.
