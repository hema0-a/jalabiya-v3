## 🐛 إصلاحات v3.3.1

**3 إصلاحات حرجة** لنظام الإعدادات + الترحيب:

### 1. حفظ الإعدادات الآن يعمل 100% ✅

**المشكلة**: عند إدخال بيانات في الإعدادات (اسم الورشة، التنبيهات، إلخ) → لا تُحفظ.

**السبب**: **Stale Closures** — في `sections-workshop.js`, `sections-data.js`, `sections-system.js`, `sections-security.js`:
- كل حقل يستخدم `saveFn({ workshop: { ...ws, [key]: v } })`.
- `ws` يُلتقط مرة واحدة عند الرسم.
- التعديل الثاني **يمحو الأول** (لأن `ws` يحتوي القيم القديمة).

**الحل**: إرسال **حقل واحد فقط** — `settings.update()` يدمج مع DB الحيّ.

### 2. الحفظ يعمل على الجوال ✅

**المشكلة**: `blur` غير موثوق على Mobile Safari/Chrome → التعديلات لا تُحفظ عند التنقل السريع.

**الحل**: `input` بـ **debounce 800ms** + `blur` احتياطي.

### 3. ترحيب باسم الورشة + الشعار ✅

**المشكلة**: الترحيب يعرض "صاحب الورشة" دائمًا.

**الحل**: `dashboard.js` يقرأ `settings.workshop.name` + `settings.workshop.logo`.

**النتيجة**: ترحيب شخصي ("صباح الخير، ورشة النور") + الشعار يظهر.
