- بحث فوري (اسم أو هاتف)

### 💰 الدفعات

- ربط اختياري بالطلب
- 4 طرائق دفع: نقدي، InstaPay، Vodafone Cash، أخرى
- إحصائيات شهرية

### 🧵 المخزون
- 7 فئات: قماش، خيوط، إكسسوارات، أزرار، أدوات، صباغة، أخرى
- تنبيه نقص (per-item + global)
- تعديل سريع للكمية (+1 / -1)
- إجمالي قيمة المخزون

### 👷 العمال
- إضافة، تعديل، حذف
- تفعيل/تعطيل
- 4 أنواع أجر: ثابت، بالقطعة، يومي، ساعي
- تتبع الرواتب + الدفعات

### 🧾 المصروفات
- 8 فئات (قماش، خيوط، إيجار، كهرباء، ...)

## 🌙 آخر التحسينات (v3.3.0)

**3 تحسينات UX + موثوقية:**

### 1. الوضع الليلي (Dark Mode) 🌙

- **زر في Topbar** — اضغط 🌙/☀️ للتبديل.
- **يتبع تفضيل النظام** تلقائيًا.
- **يحفظ التفضيل** — عند إعادة فتح التطبيق، يبقى الوضع.
- **انتقال سلس** بين الوضعين.
- تغطية كاملة: بطاقات، حقول، modals، toasts، badges، offline banner.

### 2. الحفظ التلقائي للمسودات (Autosave) 💾

- **5 نماذج مُفعَّلة**: طلب، مصروف، دفعة، صنف، عميل.
- **حفظ تلقائي** أثناء الكتابة.
- **استرجاع فوري** عند إعادة فتح النموذج.
- **Toast إرشادي**: "📝 تم استرجاع مسودة سابقة".
- **صلاحية 24 ساعة** — حذف تلقائي عند الانتهاء.
- **مُسح المسودة** عند نجاح الحفظ.

### 3. مؤشر "غير متصل" (Offline Indicator) 🔴

- **شريط أحمر** يظهر تلقائيًا عند فقدان الاتصال.
- **يتحول أخضر** عند عودة الاتصال.
- **يختفي بعد 3 ثوانٍ** من عودة الاتصال.
- **دعم كامل** للوضع الليلي + قارئات الشاشة.
