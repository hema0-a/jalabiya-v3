# أمان المزامنة السحابية — خطوات من لوحة Firebase (مرة واحدة)

مفتاح Firebase (`apiKey`) في تطبيقات الويب **ليس سرّاً** ويظهر لأي زائر؛ الحماية الحقيقية تأتي من
القواعد وتقييد المفتاح. هذه الخطوات لا يمكن تنفيذها من الكود، وتتم من حسابك:

1. **نشر القواعد**: Firebase Console ← Firestore Database ← Rules ← الصق محتوى `firestore.rules` ← Publish.
   (كل مستخدم مسجّل يقرأ/يكتب `users_v3/{uid}/…` الخاص به فقط، وكل ما عداه مرفوض.)
2. **تقييد المفتاح بالنطاق**: Google Cloud Console ← APIs & Services ← Credentials ← مفتاح الويب ←
   Application restrictions = Websites، وأضف `https://hema0-a.github.io/*` (وأي نطاق آخر تستضيف عليه التطبيق).
3. **Authentication**: فعّل فقط مزوّدات الدخول التي تستخدمها فعلاً، وأضف نطاق الاستضافة في Authorized domains.
4. اختياري: فعّل **App Check** (reCAPTCHA v3) لتقليل الاستخدام من خارج التطبيق.

## حدود معروفة
- الرقم السري (PIN) وعدّاد المحاولات محفوظان في الجهاز: يمنعان الاطلاع العابر على الهاتف المفتوح،
  لكنهما لا يصدّان من يملك وصولاً تقنياً للمتصفح (أدوات المطوّر). لحماية أقوى استخدم قفل الجهاز نفسه.
- البيانات المحلية غير مشفّرة في IndexedDB؛ احتفظ بنسخة احتياطية JSON دورية خارج الجهاز.
